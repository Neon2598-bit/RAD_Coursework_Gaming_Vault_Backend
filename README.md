# GameVault

A full-stack game review and backlog tracker built with the MERN stack and
TypeScript, for the ITS2020 Rapid Application Development coursework.

## Structure
- `backend/` - Node.js, Express, TypeScript and MongoDB REST API
- `frontend/` - React, TypeScript, Redux and TailwindCSS (coming soon)
